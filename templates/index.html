⚙️ Process

How The Model Works

A rigorous six-stage machine learning pipeline built from scratch on real-world airline data.

1

Missing Value Handling

All 539,383 records analyzed for gaps. Median imputation for numerical columns and mode imputation for categorical ensures clean, unbiased training data.

2

Feature Encoding

Categorical variables like Airline, AirportFrom, AirportTo converted to numerical using One-Hot Encoding — expanding dataset from 9 to 606 features.

3

Forward Selection

SelectKBest with f_classif scoring reduces 605 features to the 50 most statistically significant — cutting model complexity by 92%.

4

Logistic Regression

Binary classifier trained on 431,506 samples. Uses sigmoid function to output delay probability. Achieves 62.28% accuracy on 107,877 test samples.

5

Polynomial Regression

Degree-2 polynomial transformation captures non-linear feature interactions. Achieves 62.77% accuracy with R² score of 0.099.

6

XGBoost Classifier

Gradient boosted ensemble with 300 estimators, max depth 8, learning rate 0.1. Calibrated with sigmoid method for reliable probability scores. Best performing model in the pipeline.

7

Delay Cluster Profiling

KMeans clustering (k=3) groups flights into Low Risk, Moderate Risk, and High Risk delay profiles — revealing hidden patterns across routes, airlines, and departure times.

8

Flask Deployment

All models serialized with Joblib and served via Flask REST API. Real-time predictions with confidence scores and cluster profiling through a live web interface.

🗂️ Dataset

The Data Behind It

The dataset contains 539,383 real US domestic flight records sourced from Kaggle. It covers 18 airlines and hundreds of airports, capturing key flight attributes used to predict delay probability.

After One-Hot Encoding of categorical variables, the feature space expanded from 9 original columns to 606 — which Forward Selection then reduced to the 50 most predictive features for XGBoost training.

💡 Key Insights

What The Data Reveals

Patterns discovered from analyzing 539,383 real flight records across 18 US airlines.

🏆

Most Delayed Airline

Southwest Airlines (WN) had the highest delay count with 65,000+ delayed flights — also the biggest predictor in our model with a score of 31,067.

🕐

Time Is Everything

Departure time is the 2nd strongest predictor with a score of 12,492. Later in the day means significantly higher delay probability.

📅

Worst Days To Fly

Wednesday and Thursday show the highest delay rates. Saturday is consistently the safest day to travel with fewest delays recorded.

🛫

Chicago Midway Risk

MDW airport ranked as highest-risk departure point. Its congestion and weather patterns make it a critical predictor in our model.

📊

Massive Scale

Trained on 431,506 samples, tested on 107,877 — an 80/20 split across one of the largest airline delay datasets on Kaggle.

⚡

98% Feature Reduction

Forward Selection cut 605 features to just 50 — reducing model complexity by 92% while preserving predictive accuracy for XGBoost.

👨‍💻 About

About This Project

This project was built as part of a 2nd year B.Tech minor in Artificial Intelligence & Machine Learning. The goal was to apply core ML concepts — missing value handling, feature selection, and regression models — to a real-world problem.

Flight delays cost the US economy billions annually and affect millions of passengers. By building a predictive model on half a million real records, we demonstrate how machine learning can turn raw data into actionable insight.

🎯
Real World Data 539,383 actual US domestic flight records from Kaggle — not synthetic or simulated data.
